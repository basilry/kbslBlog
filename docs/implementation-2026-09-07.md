# 2026-09-07 블로그 개선 구현 기록

## 변경 결과

- 홈을 개발 기록·최근 글·대표 프로젝트 중심으로 개편하고 글 탐색, RSS, 키보드 이동과 테마 전환을 개선했습니다.
- 공개 글 목록·본문을 서버 렌더링하고 글별 제목, 설명, canonical, Open Graph, sitemap, RSS를 추가했습니다. 기존 숫자 글 URL과 관리자 작성·수정 경로는 유지합니다.
- 선택한 Obsidian 노트 하나와 참조 첨부만 가져오는 CLI를 추가했습니다. 기본 실행은 읽기 전용 검증, `--preview`는 로컬 미리보기, `--write`는 Git 제외 `.content-drafts`, `--publish`만 공개 콘텐츠를 생성합니다. 명령은 커밋·푸시·배포하지 않습니다.
- 웹 에디터의 중복 제출, 업로드 실패 후 잘못된 본문 저장, 최신 편집 내용 누락을 보완했습니다. 초안은 저장 성공 전까지 현재 브라우저에 보존합니다.
- 이미지 프록시의 대상 호스트·DNS·리다이렉트·시간·크기·MIME·픽셀 제한과 WebP 변환 검증을 적용하고 순환 리다이렉트 미들웨어를 제거했습니다.
- Next 16.3.4 / React 19.2.8, Node 22 이상, flat ESLint와 테스트·빌드 CI로 정리했습니다. GitHub Pages 전용 배포 설정을 제거했습니다.

## 검증

- 전체 TypeScript 검사 통과.
- ESLint 오류 0개. 기존 이미지 최적화·Hook 의존성 경고 11개는 남아 있습니다.
- Vitest 5개 파일, 24개 테스트 통과. 업로드 실패·재시도, 초안 복구, 프록시 허용/차단·변환, 공개 콘텐츠 및 노트 가져오기를 검사했습니다.
- Next 프로덕션 빌드 통과. 기존 Sass `@import` 사용에 대한 폐기 예정 경고는 남아 있습니다.
- 로컬 가짜 읽기 API를 연결한 프로덕션 HTTP 검사 11개 통과: 홈, 목록, 기존 숫자 글, 공개 Markdown, 초안/없는 글, sitemap, RSS, robots, 프록시 차단. 임시 공개 테스트 글은 검사 후 삭제했습니다.
- 기존 글 본문·이미지 변환·canonical이 초기 HTML에 있는 것을 확인했습니다. Next 스트리밍 응답에서는 없는 글도 HTTP 200 이후 not-found/noindex 처리가 가능하므로 HTTP 상태만으로 404를 보장한다고 주장하지 않습니다.
- 브라우저에서 홈 레이아웃과 밝은/어두운 테마 전환 확인.
- 배포 의존성 npm audit: Critical 0, High 0, Moderate 38. 남은 항목은 Tiptap 2 계열 의존성에 연결됩니다. Tiptap 3 전환에는 별도의 에디터 호환성 검증이 필요합니다.

## 운영 범위와 남은 일

- 실제 관리자 로그인, 운영 API 쓰기·삭제, Google Drive 실응답은 테스트하지 않았습니다. 백엔드의 관리자 권한 검증과 업로드 응답 계약은 운영 환경에서 최종 확인해야 합니다.
- localStorage 초안은 새로 선택한 File 썸네일을 직렬화하지 못합니다. 제목·본문·기존 썸네일 URL은 보존합니다. 업로드 재시도 캐시는 현재 에디터가 열린 동안 유지됩니다.
- 목록은 새 발행 글을 먼저 두고 기존 보관함을 이어서 페이지 조회합니다. 홈의 최근 글은 두 소스를 날짜순으로 합칩니다. sitemap/RSS는 비용 제한을 위해 기존 글 최대 100개를 읽고 RSS는 최신 50개를 포함합니다.
- Git 반영과 운영 사이트 배포는 별도입니다. 이 작업에서는 운영 서버 재시작·수동 배포를 실행하지 않았습니다. 원격 저장소에 연결된 자동 배포의 성공 여부는 별도로 확인해야 합니다.
- 발행 방법과 환경변수는 [발행 가이드](publishing.md)와 [README](../README.md)를 참고하세요.

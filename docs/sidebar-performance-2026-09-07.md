# 사이드바 응답성 개선 — 2026-09-07

- 메뉴 열림 상태를 영속 core store에서 독립된 navigation store로 분리해 본문·테마·로그인 구독 알림과 localStorage 쓰기를 제거했습니다.
- Container는 필요한 값만 구독하고, 이미 닫힌 메뉴를 다시 닫는 클릭은 상태 알림을 발생시키지 않습니다.
- 전체 메뉴 자동 prefetch 대신 포인터·포커스·터치로 선택하려는 경로만 prefetch합니다.
- 큰 배경 blur와 display 전환을 불투명 배경·180ms transform 전환으로 교체했습니다. reduced-motion과 닫힌 메뉴의 inert 처리를 지원합니다.
- 메뉴 행 전체를 클릭할 수 있고 포커스 복귀는 스크롤을 이동시키지 않습니다.

검증: 타입 검사 통과, ESLint 오류 0, 전체 테스트 26개 통과, 프로덕션 빌드 통과. 메뉴 조작의 store 알림과 저장소 접근을 검사하는 회귀 테스트 2개를 추가했습니다. 로컬 운영 빌드 브라우저에서 프로젝트 → 사이드바 → 연구/학습 이동, 메뉴 재열기·닫기, 포커스 복귀를 확인했습니다. 실제 사용자 기기의 FPS/지연 개선율은 측정하지 않았습니다.
